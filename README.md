# SpiderBot MKI

This is a 4-legged 2-DOF walking spider robot that was meant as an introduction to the world of walking robots for me! I wanted to try making something walk, and here it is!

This was fully designed from scratch by me: the CAD, the electronics, the code, etc.

I am very proud of the architecture! It's elegant and robust while staying relatively small; it runs on a keyframe-based motion system with interpolation between keyframes, with a sophisticated state machine, and it runs on a 200Hz control loop!
